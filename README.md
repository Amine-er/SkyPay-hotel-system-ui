# Hotel Reservation System – Frontend

This is the **frontend application** for the Hotel Reservation System, built using modern web technologies to deliver a fast, responsive, and accessible user experience.

## Tech Stack

- ⚛️ **React** – Declarative UI library for building components
- ⚡ **Vite** – Fast development server and bundler
- 🎨 **Tailwind CSS** – Utility-first CSS framework for rapid UI development
- 💎 **shadcn/ui** – Beautiful, accessible UI components built on top of Radix and Tailwind

## UI Preview

The app features:

- Room listing
- Booking and reservation flow
- Payment integration mock
- User-friendly error and success handling
